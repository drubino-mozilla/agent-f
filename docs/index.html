Agent F

Let AI agents work in the Firefox you're already using.

Download for Windows Download for macOS

Windows 10 or later, macOS 11 or later · All releases · Source on GitHub

Agent F connects any MCP client, such as Cursor or Claude, to your running Firefox: your profiles, your tabs and your signed-in sessions. The agent works in background tabs while you keep browsing, and never takes focus. Every result tells it what changed since its last step, so it keeps up when you close a tab or a page navigates on its own.

What an agent can do

  • Open, read and close tabs, keeping its own in an "Agent F" tab group, across several Firefox profiles at once.
  • Read pages as accessibility-style snapshots, Markdown or screenshots.
  • Click, type, scroll, choose options, drag, upload files and run scripts, even in minimized windows.
  • Answer alerts, and capture network requests and console messages.
  • Search history and bookmarks, and reopen recently closed tabs.

Install

You need Firefox 140 or later, on any channel. Download the installer for your computer and open it:

  • Windows 10 or 11: Agent-F-Windows.exe. It installs for your Windows account only, without administrator rights.
  • macOS 11 or later, Apple silicon or Intel: Agent-F-macOS.pkg. It installs into your home folder, without an administrator password.

The installer sets up Agent F, adds the add-on to Firefox and connects Cursor if you have it. Then restart Firefox and enable Agent F from the notice on Firefox's menu button. To connect another MCP client, see the README.

The installers aren't signed by Microsoft or Apple yet, so the first time, your computer warns you about them:

  • Windows: if your browser says the file isn't commonly downloaded, choose to keep it. When Windows says "Windows protected your PC", choose More info, then Run anyway.
  • macOS: when it says Apple can't check the package for malware, choose Done, open System Settings > Privacy & Security, scroll down and choose Open Anyway. On macOS 14 or earlier, you can instead Control-click the file and choose Open.

Updating: the add-on updates itself. For the rest, download and run the newest installer; it keeps your settings. Removing: on Windows, use Settings > Apps > Agent F. On macOS, open Uninstall Agent F in the Applications folder in your home folder.

You stay in control

Everything stays on your computer. The broker listens only on 127.0.0.1 and needs a secret token, and web pages can't reach it. The fedora toolbar button shows what agents are doing and has a Pause switch, and every call goes into a local audit log. Firefox needs no special flags, and sites see an ordinary browser.

Franklin the Firefox is a nod to Perry the Platypus, whose secret identity is Agent P. The red panda is the animal Firefox is named after.
